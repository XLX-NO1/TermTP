## UI Fixes Included In 1.0

The user asked to make language settings easier to find and then reported that the settings sheet could not be exited.

Implemented:

- Added a gear settings button in the main window top-right control bar.
- The gear button opens the existing settings UI from inside the main window.
- Added explicit `确定` / `OK` confirmation button at the bottom of the settings sheet.
- Language and terminal theme still save immediately through `UserDefaults`; the confirmation button is for closing the sheet, not for deferred saving.
- Added `AppState.showSettings()` and `AppState.dismissSettings()`.
- Added test coverage for presenting and dismissing the settings panel from main window chrome.

Files changed for this UI work:

- `Sources/TermCApp/AppState.swift`
- `Sources/TermCApp/Views/RootView.swift`
- `Sources/TermCApp/Views/SettingsView.swift`
- `Tests/TermCAppTests/AppStateTests.swift`
